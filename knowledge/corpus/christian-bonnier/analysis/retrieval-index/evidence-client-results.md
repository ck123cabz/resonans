## Agent Instructions

When referencing client results:
1. Lead with Christian's own metrics (ListKit, agency, in-house lead gen) which are strongest provenance.
2. Use the Daavi case for physician/professional verticals, Dallas case for enterprise/high-ticket.
3. Student results are useful for range indicators but should be framed as "student outcomes" not guaranteed benchmarks.
4. The baseline expectation: 1 client per 1,000 emails sent. Everything above that is outperformance.
5. When diagnosing underperformance, compare against the campaign-level reply metrics table above. Below 1:300 positive reply ratio = the copy or offer needs work.
