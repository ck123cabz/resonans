# Paperclip

Open-source framework designed as an operating system for running an autonomous company, complete with traditional org charts — you assign a CEO, a CTO, and so on.

## Verdict
Overly complex; it solves a problem most business owners do not actually have yet. Rejected during the Command Center evaluation specifically because it forces corporate org charts onto simple jobs — dispatching a routine content task shouldn't require staffing a fictional executive team.

## Shared failure with other wrappers
Like Vibe Kanban, Pulsia, and the desktop app, it was built bottom-up from code sessions with no underlying business context — no brand voice, audience, or content strategy underneath — which is what output quality actually needs. That gap is what the Command Center build (a UI over the Agentic OS) exists to close.
