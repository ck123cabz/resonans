# Frameworks Index, Layer Two

This file extends the layer-one map of the same name, `frameworks-index.md`, to layer two ($100M
Money Models and $100M Lost Chapters). Every named framework, formula, acronym, list and script
family in the eight layer-two files, one line each. Grep the name here, then open the home file at
the heading given. Compiled from the eight domain files below, with `pass-2-reconciliation.md`
"Layer two" (L2.1 to L2.6) applied where it overrides Pass 1. Every figure is indexed by value in
`numbers-index-layer-two.md`.

**Files covered:** `money-model.md` · `attraction-offers.md` · `first-customers-layer-two.md` ·
`upsell-and-downsell.md` · `continuity.md` · `operating-the-model.md` ·
`hormozi-record-layer-two.md` · `layer-two-sweep.md`.

**Columns.** *Type:* FRM framework, SCR script, PRN principle, MEC mechanism, WRN warning, NUM
number set, CLM claim about a result, BIO what he did. *Prov:* `[D]` the words were matched to his
own audio (Pass 2 §2 or L2.1); `[M*]` NotebookLM transcribed the audio and chose the words; `[A]`
the sources do not hold it. Where a construct belongs to someone else, its line says whose it is.
*Home:* file § heading, exact, so `grep -n '^## Heading' file` finds it. A home in a layer-one file
marks the same construct already held there.

**Standing caution.** The NotebookLM notebook holds both layers and cites by number, not by book,
so a layer-two answer is not proof that an idea is in a layer-two book. q101, q103, q107 and q108
say outright that they also draw on $100M Offers and $100M Leads. A framework repeated across
answer files is one retelling, not independent confirmation. L2.1 matched offer structures to the
audio; none of the money-model formulas was matched. Pass 2 has not passed Christian's review gate.
