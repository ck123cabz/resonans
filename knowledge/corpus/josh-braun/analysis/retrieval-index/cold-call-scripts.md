## 1. Complete Branching Cold Call Script (Notecard Format)

**Source:** P2.B1.S36
**Provenance:** [D]
**Product:** CaptivateIQ (commission calculation)

This is Braun's canonical cold call structure. It fits on a notecard, which is the design constraint.

```
STEP 1 — Mini Invitation:
"Hi James. This is Kim with X. How's your day going?
I was on your LinkedIn hoping to ask you a couple
of questions."

STEP 2 — Right Person:
"Are you still responsible for commission calculations?"

STEP 3 — Current Way:
"When you determine payouts, is it a manual process
involving spreadsheets, or is it automated?"

  IF MANUAL → STEP 4:
  "You've probably looked into automating it."
  [SHUT UP]

    IF "We have" →
    "Sounds like your commission rules were too complex."
    [SHUT UP — let them explain]

    IF "We haven't" → STEP 5

STEP 5 — Ask for Meeting:
"Does it make sense for you to invest 30 minutes so
you can see what's out there?"
```

**Design notes:**
- First name only on the opener (omit last name and company name — full names trigger resistance)
- "I was on your LinkedIn" creates context without being creepy
- The presupposition ("You've probably looked into automating it") is the key move. If they have, peel the onion. If they haven't, you've planted curiosity.
- "Sounds like your commission rules were too complex" uses labeling (Chris Voss) to draw out the real issue

## 2. Poke the Bear Flow (Full Structure)

**Source:** M-1 cluster (25+ signals consolidated)
**Provenance:** [D]

```
1. Mini invitation / permission opener
   "We've never spoken, hoping you could help me out"

2. Confirm right person
   "Do you still handle X?"

3. Current-way question
   "How are you getting Y done today — spreadsheets,
    automated, or something else?"

4. Poke the bear question (illuminating a potential problem)
   "I often hear that... How are you handling that?"

5. Presuppose familiarity
   "You've probably looked into automating it"
   [SHUT UP]

6. If interest → ask for meeting
   If no interest → detach gracefully
```

**Notecard test:** If your talk track doesn't fit on a notecard, it's too complicated.

## 3. C2FO Cold Call (B2B Fintech)

**Source:** P2.B4.S10
**Provenance:** [D]

```
STEP 1 — Right Person:
"Do you still handle outstanding invoices?"

STEP 2 — Current Way (crispy):
"How are you accelerating invoices — is it by sending
reminders, using escalation procedures, or through
early payment incentives?"

STEP 3 — Presuppose Familiarity:
"You've probably looked into Early Pay."

  IF YES → Peel the onion:
  "Sounds like the value wasn't there for you."
  [SHUT UP]

  IF NO → Deliver teaser with easy out:
  "Generally speaking, does that sound interesting
  or no?"
```

**Principle:** Statements invite objections. Questions don't.

## 4. iPod Cold Call (2010 — Complete End-to-End Transcript)

**Source:** P2.B4.S30
**Provenance:** [D]

```
OPENER (transparency):
"Full disclosure: this is a cold call."

CURRENT STATE:
"What portable music player are you using?"
→ "A Rio."

DIG INTO EXPERIENCE:
"What's been your experience with it?"
→ "Pretty good actually."

ILLUMINATE A GAP:
"The Rio holds 30 minutes of music. What do you
do on longer runs?"
→ "I... don't have a great solution for that."

PRESUPPOSE FAMILIARITY:
"What's your opinion of the iPod?"
→ "Too expensive."

LABEL:
"Sounds like the value wasn't there for you."
→ "Well, also I don't have a Mac."

RESOLVE + MICRO-COMMIT:
"iPod actually works with Windows now. If you'd like,
I can show you."
→ "Yeah, that'd be interesting."
```

**Why it works:** Zero resistance because you never pitched. Every response was a question or a label. The prospect arrived at the meeting request through their own discovery.

## 5. Kendra Warlow Transcript (Gravy Solutions — Trust-First)

**Source:** P2.B1.S38
**Provenance:** [D]

```
OPENER (disarming honesty):
"I didn't expect you to pick up. I'm actually in
the Starbucks drive-through."

SMALL TALK (genuine):
[Chat about her drink order — builds rapport]

POKE THE BEAR:
"How are you recovering failed payments today?
Are you using internal resources or an outsourced
recovery team?"

PRESUPPOSE:
"So you're probably running a failed payment report
in Stripe pretty often?"

VALUE-FIRST (no demo ask):
Offered to send instructions to run the report

RESULT:
No problem found. No sale. But Braun says Gravy is
the only company he'd call if the problem arose.

"She put my best interests before hers so I trust her."
```

**Why this matters:** The no-sale outcome is positioned as the ideal case. It demonstrates what "detached selling" looks like when the prospect genuinely doesn't have the problem. The trust it built outlasts any single transaction.

## 6. Financial Advisor Cold Call (Full Poke-the-Bear)

financial advisor."
[SHHH]

Ditch the pitch. Poke the bear.

## 7. Grubhub Cold Call: Before/After (Pitch vs. Poke)

**Source:** P2.B3.S34
**Provenance:** [D]

**BEFORE (pitching — fails):**
```
"We help restaurants get more delivery orders by
listing on Grubhub's national marketplace."
```
Problem: when you're convincing, you're losing. Restaurant owners already have a solution.

**AFTER (poking — works):**
```
"I talk to a lot of restaurant owners who miss out
on orders just because folks are loyal to the other
apps besides Uber Eats or DoorDash.

How do you make sure you're showing up no matter
which app someone opens?"
```

## 8. Real Estate: "Forever Home" Elicitation

**Source:** P2.B5.S38
**Provenance:** [D]

```
OPENER (specific property reference):
"I see you own [address]. Do you still own it?"

POKE:
"There's been a lot of interest, homes going above
market. I don't suppose you're looking to sell?"

→ "No."

ELICITATION LABEL:
"Sounds like it's your forever home."

→ "Well... we want to move to the mountains one day."
[OPENING CREATED]

NURTURE CLOSE:
Offer to add to neighborhood comp email list.
```

**Key move:** "Sounds like it's your forever home" is an extreme label that triggers the correction instinct. People correct wrong assumptions, and in correcting, they reveal their actual plans.

"If you want to be a better closer, be a better opener."

## 9. Cold Call Openers (Named Archetypes)

**Source:** P2.B6.S2, P2.B3.S15, P2.B4.S3

### The Helper
"We've never spoken, and I know you weren't expecting my call, but I was hoping you could help me out for a moment."
[PAUSE]

### The Transparency / The Gambler
"Full transparency, this is a cold call. Want to hang up or roll the dice?"

### The Connection
Name-drop a mutual contact: "Kim suggested I get in touch with you regarding..."

### The Relevance
First name only + specific detail + confirm question:
"Hi Josh, this is Mandy. I'm calling about the Inside Selling podcast. Are you still the one handling sponsorships?"

### The Shortie
"Do you have a brief moment?"

### The Bouncer
"Was hoping to bounce an idea off you. Do you have two minutes?"

### The Curiosity
"Hey Josh, this is Riley Jones. You don't know me. Want to hear something cool?"

### Preemptive Empathy Openers
- "We've never met but..."
- "I know you weren't expecting my call but..."
- "Full transparency, this is a cold call, but..."
- "You don't know me. I'm a complete stranger."
- "I probably caught you in the middle of something..."
- "I didn't expect you to pick up."

**Design rule:** First name only on cold calls. Omit last name and company name. Full intros sound like attendance-taking and trigger the guard.

## 10. Cold Call Report Card (Self-Assessment Checklist)

**Source:** P1.B2.S10, P1.B4.S6
**Provenance:** [D:vis]

### BEHAVIOR
- [ ] Listened to understand, not respond
- [ ] Paused two beats before talking
- [ ] Let go of assumptions
- [ ] Detached from outcome

### TONE
- [ ] Slowed down
- [ ] Smooth / calm / relaxed
- [ ] Casual / conversational

### FRAMEWORK
- [ ] Asked permission to chat
- [ ] Confirmed right person
- [ ] Illuminated a potential problem
- [ ] Asked prospect's opinion
- [ ] Talked about fireballs not flowers
- [ ] Asked for meeting if applicable
- [ ] Call lasted more than one minute

### OBJECTIONS
- [ ] Paused after hearing objection
- [ ] Felt confident responding
- [ ] Used mirroring and labeling to understand
- [ ] Put the ball in prospect's court
- [ ] Stayed away from convincing

**Closing reminder:** "You're for someone, but you're not for everyone."

"You can't improve at cold calling if you don't know what 'better' looks like. And you can't practice what you can't see. Not to grade yourself. To see yourself."

## 11. Objection Handling Scripts

**Source:** M-4 cluster (21+ signals consolidated)
**Core method:** Pause two beats. Acknowledge. Label. Listen.

### "I'm not interested" (20 seconds in)

```
[PAUSE two beats]

"That's okay. I know you didn't ask for the call.

Before we hang up, if I'm not overstepping, is this
a timing thing, or just not relevant?"
```

**Word-by-word psychology:**
- "That's okay" = no penalty
- "I know you didn't ask" = restores autonomy
- "Before we hang up" = low-commitment boundary
- "If I'm not overstepping" = gives control
- "Timing or not relevant" = reframes rejection as neutral classification

### "We don't have budget"

```
[PAUSE two beats]

"Seems like budgets are reserved for existing vendors."
[MUTE]

[If they elaborate, then:]

"Not sure if this is for you, but some folks like to
review options ahead of time, so when budget opens up
down the road, they already have a picture.

Is that something you'd be open to?"
```

### "Send me an email"

```
"Sure. So I don't do you a disservice by sending
irrelevant information, mind if I ask you a couple
of quick questions?"
```

### "Call me back in Q2"

```
[VALIDATE first:]
"Sounds like you've got a lot on your plate right now."
[PAUSE]

"Just to respect your time, do you mind if I briefly
give context about why I'm calling so you can decide
if it's worth hearing from me in a few months?"

[If timing truly off:]
"We send articles for [job role] about [trend].
Would it be okay if I add you to the list?"
```

### "Your price is too high"

Don't defend. Ask knowledge-gap questions:
```
"Are they using hollow core or solid doors?"
"Are they putting down RedGard for moisture protection?"
"Are they replacing your copper pipes or reusing old ones?"
```
Each question reveals something the prospect hadn't considered. "Price is the last refuge when people don't see a meaningful difference."

### "I need to think about it"

```
"Seems like you're not sure it's the right fit."
```
or:
```
"Sounds like you're weighing some other options."
```
or:
```
"Feels like the monthly payment's higher than expected."
```

If you guess wrong, they correct you. If right, they confirm. Either way you unlock more truth.

### "Is this a sales call?"

```
"Sounds like you get a lot of these calls."
```
or:
```
"You probably think I'm just another salesperson
trying to sell you something you don't need."
```
or:
```
"It is. Sounds like I'm not off to a great start."
```

### "How are you different from the competition?"

```
STEP 1 — Empathize:
"I'm sure you've seen a lot of similar options, all
promising the same thing. It can be tough to tell
what sets us apart."
[PAUSE]

STEP 2 — Redirect to their definition:
"If you don't mind me asking, what does 'different'
look like for you, given what you're trying to achieve
but haven't yet?"

[LISTEN WITHOUT AGENDA]
```

### "Take me off your list"

```
"Okay."
[Hang up. Call someone else.]
```

## 12. Poke-the-Bear Question Examples (By Industry)

**Source:** P1.B4.S14
**Provenance:** [D:vis]

These follow a consistent structure: industry-specific observation (often with a number or factual claim) + neutral question. The questions don't mention the seller's product.

**Coffee machine hygiene:**
"Coffee machines have lots of little spots where bacteria like E. coli, staph, and strep can grow... How do you usually keep yours clean?"

**SDR team scaling:**
"I often hear that once teams scale past 15 reps, call consistency drops... How are you keeping everyone on the same page?"

**Heart health:**
"Most annual physicals skip key heart disease markers like LDL particle size. How do you know if yours are in a healthy range?"

**SaaS spend:**
"Not sure about you guys, but we're seeing companies your size typically overpay 25-30% for SaaS subscriptions they no longer need. How are you ensuring you're not paying for SaaS subscriptions no one uses anymore?"

**Cold email deliverability:**
"Are you managing cold email deliverability manually checking blacklists and setting up SPF, or do you have it automated?"

**Fly fishing:**
"Not sure if this is something you're grappling with, but beginner fly fishers often say they find it challenging to tie Orvis or Triple Surgeon knots because their finger dexterity isn't quite there yet. How have you been handling that?"

**Restaurant delivery:**
"I talk to a lot of restaurant owners who miss out on orders just because folks are loyal to the other apps besides Uber Eats or DoorDash. How do you make sure you're showing up no matter which app someone opens?"

## 13. ChatGPT Prompt for Generating Poke-the-Bear Questions

**Source:** P2.B3.S9, P2.B4.S21
**Provenance:** [D]

```
Write a question that highlights a common inefficiency or
challenge for [job title] in their current workflow related
to [specific task/problem your product solves].

Use the format: "When [specific task/problem occurs], do you
[current way 1], [current way 2], or [better way your product
enables]?"

Make the question neutral, conversational, and designed to
spark curiosity about potential improvements.
```

Alternative prompt:
```
Generate a list of specific problems [company] addresses for
[buyer persona] within [target companies].

For each problem, formulate a question that begins with a
one-sentence factual observation about a common issue,
followed by a reflective question that prompts the prospect
to reconsider their current solution.

Ensure reflective questions remain neutral.
Begin with "How are you..." / "How do you..."
```

## 14. Discovery Call Talk Tracks

### Opener (anti-upfront-contract)

```
"Mind if I share what I was thinking? I'll ask questions,
you might have some for me, and at the end we decide if
there's reason to talk further. If not, that's okay too."
```

### "Stay in the Question" Deepening

```
"How are you handling X?"
→ "Spreadsheets."

"How's that been working?"
→ "Gets messy."

"Messy how?"
→ "Collaborating is a nightmare."

"How so?"
→ "Well for starters..."

"You've been in rev ops for 17 years. What's your theory
on why that is?"
```

### Ten Phrases That Make Prospects Feel Heard

1. "Sounds like you have a reason for saying that."
2. "When you say X, can you give an example?"
3. "Seems like X is important to you."
4. "Could you go into more detail?"
5. "Could you elaborate on that?"
6. "What do you mean?"
7. "I'm not tracking."
8. "Tell me more."
9. "In what way?"
10. "How so?"

### Hypothesis-Driven Opener

```
"We work with a number of VPs of Sales facing the same
challenges as you. Again and again, these types of challenges
come up: competing mostly on price, the sales cycle is too
long, inconsistent pipeline.

Is this what you're seeing? Or would you add something?"
```

### Twist the Knife (Elevating the Problem)

After they name a problem, don't solve it yet:
```
"How's that affecting the team? Morale? Burnout?"
```
Elevates a tech problem to a people/leadership/retention problem. "Big expensive problems are more urgent to solve."

### Surrendering Control Close

```
"Where would you like to go from here?"
```
