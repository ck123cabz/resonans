Six figures of one square plate, each the still lines of a different mode. Mode 1, 5 is the figure the mark is drawn from.

All six are drawn in `ink` #211513 on a clear ground, 200 units square.

- Use one pattern per piece. Crop it large so 1 or 2 lobes fill the frame.
- On `ground`, set it at 8% to 12% opacity. On `ink`, ask for the `air` version.
- Keep type off the dense middle of a figure.
- `mode-1-3.svg` is the calmest and `mode-5-7.svg` the busiest. Pick by how much is going on in the layout around it.
