The Resonans mark, wordmark and lockups. Each file has one fixed colour, named in its file name, because a picture placed as an image cannot take a colour from the page.

| File | Ink | Place it on |
|---|---|---|
| `lockup-horizontal-ink.svg`, `lockup-stacked-ink.svg`, `wordmark-ink.svg`, `mark-ink.svg`, `mark-small-ink.svg` | `ink` #211513 | `ground`, `ground-raised`, light photos |
| the same five ending in `-air.svg` | `ground` #FBF5F5 | `ink`, `root`, dark photos |
| `mark-root.svg` | `root` #F14441 | `ground` or `ink` only |
| `icon-app.svg` | `ground` mark on an `ink` tile, 1024 units | app icons and avatars |
| `favicon.svg` | the small-cut mark on an `ink` tile | browser tabs, 16px to 64px |

- Use `mark-small` at 32px and under. Its stroke is 24 units; `mark` has 16.
- Keep clear space of half the mark's width on every side.
- Minimum width: 96px for a lockup, 16px for `mark-small`.
- Do not recolour a file. Ask for a new one.
