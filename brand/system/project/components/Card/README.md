A raised surface for one thing: a deliverable, a client, a week. Use class `rs-card` on an `article` or a `div`.

**You provide** a `subtitle`-size heading, one or two sentences in `ink-soft`, and at most one action.

- Ground is `ground-raised` with a `stroke-hair` border in `line`. Radius `radius-3`. Padding `space-6`, or `space-4` on phones.
- No shadow anywhere in the system. Height is a lighter ground and a hairline.
- A card holds one Quiet button at most. If it needs two actions, it is a page.
- Do not nest cards. Do not colour a card's edge to show status; put a Tag inside it.
