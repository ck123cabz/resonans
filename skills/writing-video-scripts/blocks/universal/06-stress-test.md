# Block 06: the stress test

Run before a script goes to recording. Two lens walks and one cold read, in parallel, each by an Opus subagent. Walks follow `skills/lens/references/challenge-walk.md` by hand.

| Walk | Lenses | Asks |
|---|---|---|
| Funnel and retention | `ryan-mathews` and `nate-herk` | Does the hook earn the next 10 seconds? Is there an offer? Is the call to action right for this surface and its traffic? Does it hit a known failure? |
| Art direction and cold read | `jason-murray`, then the viewer from block 01 | One insight or a feature tour? One visual world? Does each visual read with the sound off? Where would the viewer stop, what line confuses him, what claim does he not believe? |

The cold read also checks the order of ideas: read each beat's first line right after the previous beat's last line. The aggregate claim comes first, then one example opened with "for example". Going back to an aggregate after the example needs a bridging line. Flag any claim whose logic the viewer cannot rebuild from the lines before it. Three walks once passed a one-lead example followed straight by a firm-wide headcount claim; Christian caught that it didn't add up, and moving the scale line ahead of the example fixed it.

Each finding carries a severity (blocker, should fix, nit), the exact line, and a fix that obeys block 04.

## After the walks

The walks' own files are the record. Write no merged report and no notes file for the person: on 23 Oct 2026
Christian asked for grilling in place of reviews, because confirming each call in a round gets his feedback faster.

- Check every source quote a finding rests on against the saved file before it goes into a question.
- Grill the person with the `grilling` skill. One question per line or slot, holding its id, the current wording
  and the reason in one sentence. The first option is the recommended fix; a competing walk's wording is the next
  option, and keeping the line as it is is always one. Ask the findings several walks share first.
- Apply what they pick, to the script and every mirror of it (a recording script, the cards' anchors).
- Send a question only another named person can answer (a native speaker's ear, a source behind a login) to
  that person, and leave it out of the round.
- Re-run the linter. At the end of the script file, record in one line which walks ran, on what date, and the
  lint result.
